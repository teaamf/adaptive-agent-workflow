# First research revision

29 September 2026. The general draft was saved before this pass. This is a design record, not experimental evidence.

Sources reviewed: NIST SSDF, NASA systems-engineering tailoring, Anthropic composable agent patterns and UKHSA reproducible analytical pipelines.

Adopted: a small invariant core with composable domain profiles; reuse existing project processes; minimal missing infrastructure rather than a mandatory foundation; task-appropriate team size; distinct data/research/document evidence; and explicit assurance profiles. Institutional requirements and vendor tooling were not imported as universal rules.

Challenge for the second pass: prevent tailoring from becoming a gate-bypass mechanism; distinguish computational reproduction from valid findings; test claimed portability without equating file readability with host compatibility.
